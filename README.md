---

## 🚀 Sobre o Projeto

O **Farmácia Dev** é uma plataforma healthtech web responsiva e interativa que consome uma API RESTful para realizar o gerenciamento completo do recurso **Categoria** (CRUD). O projeto foi desenhado com uma interface moderna, focando na usabilidade do usuário e na integridade dos dados de estoque e catálogo farmacêutico.

---

## ✨ Funcionalidades

- **Home Page**: Interface moderna com banner principal, destaques de serviços e navegação fluida.
- **Listar Categorias (GET)**: Exibição visual em formato de cards de todas as categorias cadastradas na API.
- **Cadastrar Categoria (POST)**: Formulário validado para criação de novas categorias.
- **Editar Categoria (PUT)**: Atualização dinâmica de dados de categorias existentes.
- **Deletar Categoria (DELETE)**: Confirmação e remoção de categorias cadastradas.
- **Feedback Visual**: Indicador de carregamento (Loading Spinner) durante as requisições assíncronas.

---

## 🛠️ Tecnologias Utilizadas

- **React 18** + **TypeScript**
- **Vite** (Build Tool)
- **Tailwind CSS v4** (Estilização Utilitária e Responsividade)
- **React Router DOM v6** (Navegação SPA e Rotas Parâmetro)

## 📦 Como Executar o Projeto Localmente

### Pré-requisitos
- Node.js (versão 18 ou superior)
- npm ou yarn

### Passo a passo

1. **Clone o repositório:**
`git clone https://github.com/jvribe/projeto_final_bloco_03.git`

2. **Acesse a pasta do projeto:**
`cd projeto_final_bloco_03`

3. **Instale as dependências:**
`npm install`

4. **Inicie o servidor de desenvolvimento:**
`npm run dev`

5. **Acesse no navegador:**
http://localhost:5173
